# November queued-content revision

Scope: the 68 unpublished approved Facebook, TikTok and YouTube posts read on 4 November 2026. Instagram and already published content are excluded.

The editorial file contains 23 date-specific hooks, story beats and concise descriptions checked against the current website catalogue. Captions keep platform-specific book-finding directions. Facebook uses the catalogue Amazon URL and only repeats Kindle Unlimited availability when the catalogue confirms it.

The renderer creates nine-second H.264/AAC videos with immediate hook (2.4 seconds), story beat (3.6 seconds), and the exact genuine cover with Amazon search instructions (3 seconds). Existing licensed audio is retained. Portrait output is 1080x1920; Facebook feed video is 1080x1350. All text is deterministic, without generated plot claims or paid AI calls. Original media remains stored.

Verification covers duration, codecs, sample rate, square pixels, dimensions, caption/title limits and source versions. Opening, middle and closing screens are reviewed visually. Remote uploaded media must match the local SHA-256 checksums before the version-guarded database updates run. Dates, approval states, ownership, campaign IDs and publishing records are preserved.

The temporary upload function accepts only an exact allowlist of immutable object paths and hashes, requires both the project JWT and an expiring maintenance token, and is disabled after use. No production secret values are copied into this repository.

These changes are hypotheses for improving retention and book discovery. No increase in watch time, clicks or sales has yet been measured.
